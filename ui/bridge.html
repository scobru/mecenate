Mecenate wallet bridge

Starting…

Keep this window open while you use Mecenate. It only relays Mecenate's requests to your wallet: reads, switching to a supported chain, calls to the Mecenate contract, token approvals for it, and signing the fixed message that unlocks your Mecenate encryption key. Everything else is refused.

Only sign the key message from the Mecenate app: whoever gets that signature can decrypt the data you bought.
